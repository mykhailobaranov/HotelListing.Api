HotelListing API

A simple RESTful API for managing hotels and countries. 
This is an **educational project** developed to learn and practice ASP.NET Core Web API concepts.

Technologies & Tools
**.NET 9** (ASP.NET Core Web API)
**Entity Framework Core** (Code First)
**MS SQL Server** (Database)
**Swagger / OpenAPI** (Documentation)

Key Concepts Learned
During the development, I implemented and practiced:
**CRUD Operations**: Create, Read, Update, Delete.
**DTO Pattern**: Separation of Domain Entities and Data Transfer Objects.
**Relationships**: Handling One-to-Many relationships (Country -> Hotels).
**EF Core**: Migrations, Seeding, LINQ queries.
**Architecture**: Controller-Service-Repository pattern (in progress).
**Error Handling**: Solving JSON cycle issues, Global Exception Handling.
